Embedding the calculator

This is a sample host page. The calculator below is the full latest version, embedded by live reference, so it always reflects the newest design and math. It auto-resizes to fit its content: no scrollbars, no fixed height guessing. Copy the snippet below into any IBM/Turbonomic page.

Prefer a compact inline widget without the hero banner? Append ?embed=1 to the src and the marketing header is hidden automatically.

Standalone use: just open index.html directly, or host it anywhere (it is already wired for GitHub Pages in this repo). It has no build step and no dependencies beyond the IBM CDN it already references.
